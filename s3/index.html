★ GitHub

An S3 browser whose every button is Python. Each action calls a method in aws_twin/web/S3__Browser.py, which calls OSBot-AWS's S3() or boto3; botocore signs the request as it would for AWS; the Python twin in this page answers it. Buckets are kept in this browser through sg-vfs's IndexedDB provider. Nothing is sent to AWS until you choose Live session: then the same calls go to the real account with the session pasted on the sessions page, read-only unless you allow writes. The first load fetches about 25 MB of Python; the browser caches it after. How the Python twin works →

aws.twin.sgit.ai

    
The AWS twin: an AWS-shaped interface (S3, Lambda, EC2, IAM, billing, logs) whose backend is a vault, with a live session as one backend among several. One instance in the twins family; the primitive is defined on twins.sgit.ai. All content CC BY 4.0; the code is Apache-2.0.
