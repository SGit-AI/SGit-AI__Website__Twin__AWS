**An S3 browser whose every button is Python.** Each action calls a method in `aws_twin/web/S3__Browser.py`, which calls [OSBot-AWS](https://github.com/owasp-sbot/OSBot-AWS)'s `S3()` or boto3; botocore signs the request as it would for AWS; the Python twin in this page answers it. Buckets are kept in this browser through [sg-vfs](../assets/vendor/sg-vfs/v0.1.0/README.md)'s IndexedDB provider. Nothing is sent to AWS. The first load fetches about 25 MB of Python; the browser caches it after. [How the Python twin works →](../python/index.md)
