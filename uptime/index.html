aws.twin.sgit.ai / uptime

Uptime checks from every region, with reports only a vault can read

Deploy a Lambda function that checks whether websites are up, to as many AWS regions as you pick, on a schedule. Each report is encrypted to a public key and appended to an sgit vault's lane, which only the private key's holder can read. Everything here is boto3 running in this page: against the twin by default, so you can deploy, run, break and read it with no AWS account, and against your account with the session from the sessions page. The function is one Node.js file with no dependencies, the same file in the twin and on Lambda. The plan, and why Node.js →

aws.twin.sgit.ai

    
The AWS twin: an AWS-shaped interface (S3, Lambda, EC2, IAM, billing, logs) whose backend is a vault, with a live session as one backend among several. One instance in the twins family; the primitive is defined on twins.sgit.ai. All content CC BY 4.0; the code is Apache-2.0.

⚠ Participant disclosure: published by the sgit project, which builds the vault this twin stores into and the server components its first job deploys. Not affiliated with, endorsed by, or sponsored by Amazon Web Services; AWS service names identify the interfaces this twin mirrors.
