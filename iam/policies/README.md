# Policies for aws.twin.sgit.ai's IAM guidance

Inline policies for IAM Identity Center permission sets, and the bucket CORS rule the S3 browser needs to
reach a bucket straight from the page. Replace `BUCKET_NAME` (and `FOLDER`) before use; the page
https://aws.twin.sgit.ai/iam/index.html says how, and which permission set each is for.
