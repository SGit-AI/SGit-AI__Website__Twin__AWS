Admin & engineering

A static site and a browser application in one repository, with no build step to serve and two scripts to check. Source at SGit-AI/SGit-AI__Website__Twin__AWS.

2. Run it

# serve the tree; any static server does, and file:// works for the twin page too
python3 -m http.server 8080
# then open http://localhost:8080/twin/index.html

# the interface tests: the same script against the memory and vault backends
node admin/build/test.js
# the site checks: internal links resolve, nav identical on every page, one version string, name-watch
node admin/build/validate.js

Both scripts exit non-zero on a failure and are the release gate. There is no dependency to install: the twin's code runs in Node and in the browser unchanged.

3. What the twin stores in the browser

KeyStoreHolds
aws.twin/vaultlocalStorageThe vault document: working state, commits, head. Exportable as JSON from the snapshots page; reset from the same page.
aws.twin/sessionsessionStorageA pasted session, with its expiry, for the tab's lifetime. Cleared from the session page or by closing the tab.
aws.twin/uilocalStorageThe chosen backend, account and region.

No cookies, no analytics, no request to any host: the twin page makes no network call after it loads.

4. The validator, and the name-watch

admin/build/validate.js walks every HTML page and checks: a title, a description and a canonical link; every relative href and src resolves to a file in the tree; the nav block is identical on every page once the ../ prefix is removed; the version string on every page matches the latest row of the release history; and the name-watch, the hub's check, that no capitalised <Word> Twin appears outside the allow-list of terms ruled on at twins.sgit.ai/naming. This site's own usage is lower case, the AWS twin, so the allow-list is the hub's four terms and nothing else.

5. Releases

Semantic versions, one row per release in the release history, the version shown in the nav and footer of every page, and the twin's code released as part of the site so that the code that will one day hold a session is a fixed, versioned copy. v0.3.0 is the first release, of 2026-10-21.

aws.twin.sgit.ai

The AWS twin: an AWS-shaped interface (S3, Lambda, EC2, IAM, billing, logs) whose backend is a vault, with a live session as one backend among several. One instance in the twins family; the primitive is defined on twins.sgit.ai. All content CC BY 4.0; the code is Apache-2.0.
