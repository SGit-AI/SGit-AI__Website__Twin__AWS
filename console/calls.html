aws.twin.sgit.ai

    
The AWS twin: an AWS-shaped interface (S3, Lambda, EC2, IAM, billing, logs) whose backend is a vault, with a live session as one backend among several. One instance in the twins family; the primitive is defined on twins.sgit.ai. All content CC BY 4.0; the code is Apache-2.0.

    
↗ twins.sgit.ai — the hub · ↗ sgit.ai — the parent project · ↗ sg-compute.sgit.ai — ships the S3 twin · ↗ the article · ↗ the network

    
⚠ Participant disclosure: published by the sgit project, which builds the vault this twin stores into and the server components its first job deploys. Not affiliated with, endorsed by, or sponsored by Amazon Web Services; AWS service names identify the interfaces this twin mirrors.

    
site v0.4.2 · engineering · no analytics, no cookies; third-party code only where a page says so: Python (Pyodide, and wheels from PyPI) on the twin's pages, and the AWS SDK for JavaScript on the calls page when you measure it
